# Пиксельные рилсы из кода

Вертикальные мультики 1080×1920 про AI: пиксельный герой в комнате, заголовки и карточки сверху, субтитры по словам и **твой голос**. Видео-нейросети не нужны: каждый кадр рисует код, поэтому без глюков и всегда в одном стиле.

## Установка (один раз)

Нужны [Node.js 18+](https://nodejs.org) и [ffmpeg](https://ffmpeg.org/download.html).

```bash
npm install
npm run setup          # скачает браузер для рендера
pip install openai-whisper   # необязательно: точные субтитры по голосу
```

## Как сделать ролик

1. **Сценарий.** Попроси Claude: «Напиши сценарий в формате `scripts/demo.json` на тему: …». Сохрани как `scripts/<имя>.json`.
2. **Текст для озвучки:**
   ```bash
   npm run text -- scripts/<имя>.json
   ```
3. **Запиши голос** на телефон (диктофон, тихая комната, телефон в 15–20 см) и положи файл в `voice/<имя>.m4a`.
4. **Синхронизация субтитров** (по желанию, но так лучше):
   ```bash
   python tools/align.py voice/<имя>.m4a
   ```
5. **Рендер:**
   ```bash
   npm run render -- scripts/<имя>.json --voice voice/<имя>.m4a
   ```
   Готовый ролик: `out/<имя>.mp4`. Быстрый черновик без голоса: `npm run render -- scripts/<имя>.json`. Только первые 5 секунд: добавь `--preview 5`.

## Сценарий

```json
{
  "title": "Название",
  "scenes": [
    {
      "say": "Что ты говоришь. *Акцентные слова* в звёздочках станут оранжевыми.",
      "title": "Белый заголовок",
      "accent": "оранжевая подпись",
      "num": 2,
      "pose": "point",
      "card": { "type": "stat", "label": "подписчиков", "value": 1600, "suffix": "+" }
    }
  ]
}
```

**Позы героя (`pose`):** `idle`, `point`, `finger_up`, `wave`, `shrug`, `crossed`, `think`.

**Карточки (`card.type`):**

| тип | поля | что показывает |
|---|---|---|
| `stat` | `label`, `value`, `from`, `suffix`, `items: [{label, value}]` | набегающая цифра |
| `chat` | `text`, `placeholder`, `tags` | запрос к ИИ печатается по буквам |
| `list` | `title`, `items` | пункты отмечаются по очереди |
| `bubble` | `label`, `text` | облачко-сомнение |
| `image` | `src` (путь от файла сценария), `badge` | скриншот, например статистики |
| `versus` | `left`, `right`, `leftNote`, `rightNote` | «нейросеть ✗ vs код ✓» |

## Свой герой

Внешность задаётся в `hero.json`: цвета кожи, волос, глаз и худи, шапка, борода, очки. Рисунок героя находится в `src/scene.html` (функция `drawHero`). Отправь Claude своё фото, и он подстроит героя под тебя.
